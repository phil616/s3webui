# v1.0.1

This patch release corrects the web interface in v1.0.0. It restores the upstream
author's page templates, stylesheet, logo and browser interactions, removes the
replacement SPA, and adds Chinese/English localization to the original interface.
The Go/PostgreSQL backend adapts its pages and API responses for those existing
templates. Upstream's original AGPLv3 terms and attribution remain in effect.

## Downloads

- `s3webui_v1.0.1_linux_amd64.tar.gz`: Linux x86-64 binary, its matching source
  archive, license notices and run instructions.
- `s3webui_v1.0.1_source.tar.gz`: complete corresponding source with vendored Go
  dependencies and the original frontend build inputs.
- `SHA256SUMS`: SHA-256 hashes for both archives.

Follow `README.release.md` in the Linux package to configure PostgreSQL, the
administrator account, encryption key and public URL. The packaged source is
available to the running application at `/source` when `SOURCE_ARCHIVE` points to it.

The v1.0.0 tag and release files are unchanged. v1.0.1 remains an independent
downstream version of phil616/s3webui and does not change the upstream project's tags.

## Verification

Validated on Windows with PostgreSQL and Chrome, plus a Linux amd64 cross-build.
Frontend, Go/PostgreSQL and browser checks passed locally. GitHub Actions run:
[Go and bilingual UI](https://github.com/phil616/s3webui/actions/workflows/ci.yml).
See [validation details](../VALIDATION.md) for scope and limitations.
