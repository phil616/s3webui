# v1.0.0

这是 phil616/s3webui 下游 Go/PostgreSQL 版本的首次发布。
本仓库的版本号独立于 wenisch-tech/s3webui 上游；不代表上游同名版本。

## 变更

- Go 后端与 PostgreSQL 应用数据存储，替代 Java/Spring Boot/H2 运行入口。
- 账号、持久化会话、加密 S3 凭证、授权和审计记录。
- 官方 AWS SDK for Go v2，桶和对象分页、上传/分段上传、下载、复制/移动、版本及桶配置。
- 简体中文和英文界面，语言偏好保存及日期、数字本地化。
- 手动审查上游更新，按需采用、移植、跳过或延期。
- 保留原作者署名和 AGPLv3；发布包提供当前版本完整对应源码。

## 下载和运行

- `s3webui_v1.0.0_linux_amd64.tar.gz`：Linux x86-64、CGO 禁用的可执行文件，以及源码归档、许可和运行说明。
- `s3webui_v1.0.0_source.tar.gz`：该版本完整源码、Go 依赖和构建/部署脚本。
- `SHA256SUMS`：上述文件的 SHA-256 校验值。

解压 Linux 运行包后按其中的 `README.release.md` 配置 PostgreSQL、管理员、加密密钥和 PUBLIC_URL。
`./s3webui --version` 可查看构建版本及对应提交。使用包内 `source.tar.gz` 设置 SOURCE_ARCHIVE，
应用会在登录页和应用页提供 `/source` 下载。

## 兼容性和迁移注意

对象仍存放在 S3，PostgreSQL 仅存放应用数据。本版本不自动导入上游 Java/H2 的账号、凭证或审计数据。
目前不提供 OIDC、厂商专用 IAM 和全部 AWS S3 产品功能。
S3 支持范围和应用上传限制见 `docs/S3-COMPATIBILITY.md`。
真实 AWS/目标兼容存储验收、Docker/Compose 实际运行、Kubernetes 部署不在本次本地验证范围内。

## 验证

Go/PostgreSQL 集成测试、26 项前端测试、桌面/移动端浏览器流程、Helm 模板与工作流静态检查已通过。
更详细的环境和验证边界见 `docs/VALIDATION.md`。
